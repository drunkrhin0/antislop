# Introduce the rule registry in version 2.0

Version 1.8 preserves the hand-maintained skill format while correcting contradictions and score reporting. Version 2.0 moves shared writing rule definitions into one machine-readable rule registry and renders generated artifacts from it. This is a major release because it changes score calculation, output fields, rule activation, and the maintenance interface. Keeping 1.8 separate gives existing users a compatible correction release before those contracts change.
