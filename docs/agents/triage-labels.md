# Triage labels

These are the labels actually configured on this repo's Forgejo instance, with their
descriptions as recorded there. Use these, not the default Matt Pocock triage set:
`needs-triage`, `needs-info`, `ready-for-human`, and `wontfix` are not configured here.

| Label | Meaning |
| --- | --- |
| `ready-for-agent` | Spec is ready for implementation by an agent |
| `ready-for-agent-review` | Implementation PR is ready for fresh-context automated review |
| `ready-for-human-review` | Automated review and required checks passed; awaiting human review |
| `blocked` | Work cannot proceed. State why and the next action |
| `long-term` | Strategic work that follows current acceptance and prerequisite milestones |
| `agent-task` | Loop-eligible: one issue in, one PR out |
