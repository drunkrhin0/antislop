# Shared Antislop contract

Load this compact contract with either active mode. Follow a context pointer only when its condition matches the request.

## Output integrity

Before returning output, check for leaked markup, placeholders, hidden characters, prompt tokens, and changed link targets. Report these defects separately from formulaic-writing risk. They never change the score.

## Conditional references

- For Draft, Revise, Transform, Recreate, author gaps, claim evidence, or a controlled rewrite, read [preservation-contract.md](preservation-contract.md).
- For review statuses or substance analysis, read [review-contract.md](review-contract.md).
- When the request names a medium, venue, locale, fiction, or LinkedIn profile, read only the matching section of [routing-contract.md](routing-contract.md).
- When the user explicitly requests the Human Review browser workflow, read [human-review.md](human-review.md).
- When a rule needs a concrete before-and-after example, read [examples.md](examples.md).

## Rules precedence

1. Voice and authenticity win. Take a position and be specific.
2. Structure rules outrank vocabulary substitutions. Rewrite the sentence when a word swap leaves the pattern intact.
3. Positive guidance outranks an individual ban. Land attention on the target behavior.
